## 2. 진단 — Compose 1차 포팅이 구려진 이유

1. **폰트 미탑재**: preview는 Space Grotesk(헤딩)+Inter(본문)인데 앱은 시스템 Roboto → 인상의 절반 상실
2. **카드 luminance 부족**: 웹의 `backdrop-blur` 없이 5.5% 흰색 오버레이 = 죽은 회색 (Material 지침 위반: 다크에서 표면은 *밝기*로 떠야 함)
3. 배경 블룸 알파 과소(0.07~0.10) → 그냥 검은 화면
4. 세로 고정 없음 → 가로에서 레이아웃 파괴
5. **모션 0**: 화면 전환 즉시 컷, 카드 등장·값 변화·탭 피드백 전무

## 3. 디자인 시스템 v2 (개정)

- 배경: `#0A0B0E→#111318` 수직 그라데이션 + 슬레이트 블룸 2개(α .14~.18) — 살아있는 배경
- **표면(luminance 위계)**: 카드 = 불투명 `#16191F` + 1dp 12% 백색 보더(상단 엣지 하이라이트 효과). 시트 = `#1B1F26`
- 텍스트: T1 `#EEF1F6` / T2 `#9DA3B0` / T3 `#646A77` (순백 금지 유지)
- 액센트: 슬레이트블루 `#86A4C8` 단일 (변경 없음). 등급색: Good `#79B89A` · Fair T2 · Bad `#C2A878` · Danger `#C88686`
- **타이포**: Space Grotesk(워드마크·타이틀·수치) + Inter(본문·라벨). variable TTF + `FontVariation`(minSdk 31)
- 모션: 전환 fade+slide 300ms / 값 변화 animate 250ms / 탭 scale 150ms / 펄스 점은 상태 표현에만
- 세로 고정(`screenOrientation="portrait"`)

## 4. 플로우 맵 v2 (빠졌던 상태들 추가)

```
[Spaces]
  ├─ scanning (펄스)                          ← 기존
  ├─ empty 상태: 한 줄 힌트 (15초 후)          ← 신규: 영원한 침묵 금지
  ├─ 카드 탭 → connecting (카드 내 스피너)     ← 신규: 무반응 구간 제거
  │     ├─ 실패 → 카드 복귀 + 한 줄            ← 신규
  │     └─ 성공 → [Space] 전환 (fade+slide)    ← 신규: 컷 금지
  └─ My AI 버튼 → [My AI 시트]                 ← 신규
[Space]
  ├─ 헤더: 공간명 + 컨텍스트 라인(외부온도·재실) ← 신규: descriptor 정보 활용
  ├─ AI Auto 칩: 탭 → Thinking(칩 내 상태) → 적용 ← 강화: 진행이 칩 안에서 보임
  ├─ 결정 이유 한 줄 (투명성 원칙)              ← 신규: reason 표시(이전엔 버림)
  ├─ 기기 카드: 값 변화 애니메이션               ← 강화
  ├─ 연결 끊김 → 자동으로 [Spaces] 복귀          ← 신규
  └─ ‹ Spaces
[My AI 시트]                                    ← 신규 (복리효과 가시화 = F-A8)
  └─ 내 휴대 선호 3줄(아이콘+수치) + "N corrections · M spaces"
```

원칙 유지: 글 최소화(이유 한 줄도 12sp T3), 목표값 설정 요구 금지, AI 모드토글 없음.
